# 页面模式

本页规定信息结构与视觉层级，**不改变**任务规则或 Flutter JSON 格式。[用户提供的「今日」参考图](references/today-stone-reference.png)是默认视觉的第一参照；旧 SwiftUI 截图补充复杂状态与交互。最终验收在 Flutter 真机窗口完成。

## 主窗口框架

```text
┌─────────────────────────────────────────────────────┐
│ macOS 标题栏 / 窗口控制                              │
├──────────────┬──────────────────────────────────────┤
│ 序           │ 工作区 / 当前页 · 全局操作             │
│ 工作区       ├──────────────────────────────────────┤
│  今日        │ 页面标题                         主动作 │
│  事项        │ 说明 / 筛选 / 展示方式 / 批量操作        │
│  蓝图        │                                      │
│  …           │ 当前页面内容                          │
│ 记录         │                                      │
│  …           │                                      │
│ 设置         │                                      │
└──────────────┴──────────────────────────────────────┘
```

侧栏常态约 216pt，不随内容页宽度变化；选中态用浅青灰圆角底、深青绿文字和图标共同提示。顶部约 64pt，白色工具区用细线与内容区分隔：左侧面包屑「工作区 › 今日」，右侧是搜索和当前主题「石墨」。页面标题只出现一次。内容最大宽度约 1120pt，窄窗口工具栏换行，列表仍可滚动。主窗口最小 900×620，任何弹窗必须能在此尺寸下完整访问底部操作。

侧栏顶部是约 36pt 的「序」方形标记、应用名和一句“把计划变成行动”；下方用低对比度组名区分工作区与记录。设置入口贴近侧栏底部。参考图只展示部分主导航，Flutter 已有的蓝图、四象限等功能必须继续可达；新增导航项应遵循同一组名、行高和选中样式，不为复刻截图而删除入口。

### 今日空态：参考图的基准构图

内容从上到下为：小号青绿色日期 → 30pt「今日」标题 → 一条细分隔线 → 中央空态。空态由日出线性图标、主句“今天还没有安排事项”、辅助句“从一件重要的事开始，安排好今天的节奏。”、唯一实心「添加事项」按钮和 `⌘ N` 快捷键提示构成。整组在标题下的可用内容区居中，图标与文字、主按钮之间留足空间；不能只显示一句“今天暂无事项”。

有任务时，空态整组替换为今日任务内容，主要添加入口移至页面头部；同一状态不重复出现两个同权重的添加按钮。日期和标题位置保持稳定。仅任务列表为空而日历/同步失败时，显示相应错误或权限状态，不用“没有安排事项”掩盖失败。

## 页面清单

| 页面 | 第一眼应看到 | 主动作 | 核心展示 | 必备状态 |
| --- | --- | --- | --- | --- |
| 今日 | 日期、单一「今日」标题、按蓝图执行的任务 | 添加事项 | 蓝图分组、未归属任务、完成进度、临近纪念日 | 参考图式空态、阻塞、加载、权限失败 |
| 收集箱 | 未安排且待处理的任务 | 添加事项 | 任务系列与分类/搜索 | 无数据、筛选无结果 |
| 事项 | 范围、数量、搜索、分类、列表/四象限 | 添加事项 | 独立系列卡；默认收起，逐卡展开 | 待处理/收集箱/已处理/全部、阻塞、完成反馈 |
| 四象限 | 四个象限的优先级与数量 | 添加事项 | 每项任务按自身象限出现一次，系列关系可见 | 空象限、窄窗口单列 |
| 蓝图 | 目标与进度 | 新建蓝图 | 任务蓝图卡、独立蓝图卡、归档筛选 | 空库、导入失败、AI 预览、历史 |
| 日历计划 | 日/周/月与选中日期、系统日历状态 | 安排事项 | 日期任务、时间块、外部日程、可用时段 | 未授权、空日程、冲突、同步失败 |
| 分类 | 类别名称、图标、使用数量 | 新建分类 | 类别卡与对应任务 | 默认/空类别、删除影响预览 |
| 纪念日 | 最近纪念日与倒计时 | 添加纪念日 | 公历/农历、隐私、提醒与准备任务 | 无日期、闰月、权限失败 |
| 已处理 | 已完成与已取消分区 | 恢复/查看 | 状态与完成时间 | 空历史、长列表 |
| 日报 | 当前日期与历史 | 创建/生成日报 | 生成预览、已保存内容、周复盘 | 生成中、长度校验、失败 |
| 设置 | 外观、数据、同步、通知、AI、更新 | 随设置项 | 当前值与生效说明 | 权限、密钥、同步冲突、更新失败 |

## 事项工作台

页面顺序：标题与一句说明 → 范围选择（带各范围计数）和列表/四象限切换 → 搜索与分类 → “任务系列”结果标题和匹配数 → 系列卡片 → 结果说明/蓝图入口。默认范围「待处理」，默认列表，所有系列收起。范围切换清除展开状态；同范围内搜索、完成和视图切换保留用户手动展开状态。筛选只命中子任务时，主任务作为上下文显示但不加入匹配数。

系列卡顶部先给根任务状态与日期，再给直接子项进度和阻塞数；展开后的树线和缩进不能让长标题难读。主任务标题点击打开只读详情，完成圆圈立即提交并提供反馈，更多菜单保留编辑、添加子任务、安排、取消/恢复和删除。批量模式与普通点击有明确边界，危险操作先显示受影响任务与后代数量。

参考：[旧版事项 V3](../mockups/tasks-macos-v3.md)。其“默认收起、独立卡片、子任务归属、计数不变”是行为约束；色值和 SwiftUI 组件不是 Flutter 实现 API。

## 蓝图工作台

标题与说明 → AI 创建、模板、导入、变更记录和归档筛选 → 自适应卡片网格。宽度足够时两列，窄窗口一列；卡片最小有效宽约 280pt。任务根节点卡和独立 `BlueprintItem` 卡必须标清类型。任务蓝图的树线表达拆解，依赖线表达执行顺序，两者视觉不同；节点拖动、缩放有键盘/列表等效操作。独立蓝图详情按目标、进度、阶段、里程碑、关联任务、工作流顺序阅读；AI 重规划先预览变化再确认。

空库展示用途说明与唯一创建入口；导入错误保留当前库，撤销失败说明后来变更的冲突。完成进度来自任务 ID，阶段和里程碑不伪装为已完成任务。参考：[任务视图架构](../task-views-architecture.md) 与旧版 `legacy-macos/Sources/Quadrant/BlueprintViews.swift`。

## 日历、纪念日与日报

日历的日期任务、执行时间块、截止、外部系统事件必须在同一日期坐标中有不同样式。日/周/月切换后右侧任务系列清单位置与筛选保持一致；月视图选日期不把清单替换为另一套内容。时间冲突先预览，不让拖拽直接破坏安排。参考：[日历重规划](../calendar-plan-redesign.md)；此文含尚未落地的产品规则，Flutter 页面实现以迁移进度核对。

纪念日首先展示下一次发生日期与倒计时，再给类型、备注和准备任务。隐私模式在主窗口、通知、菜单栏统一隐藏真实名称。日报先让用户确认日期和字数，再展示草稿，最后保存或复制；历史是只读阅读，不与草稿混排。系统权限拒绝和 AI 生成失败都提供可继续使用本地内容的路径。

## 响应式与内容伸缩

- 900×620：主窗口最小尺寸。工具栏可分两行；弹窗可滚动且主操作不被裁掉；蓝图卡一列。
- 1200×800：标准工作台。侧栏和内容区同时可见；系列卡保持舒适行长；蓝图通常两列。
- 1600×1000 及更宽：内容不无限拉伸，右侧留呼吸空间；不得把长说明拆成过宽单行。
- 文字 1.5 倍、中文标题超过 30 字、蓝图目标超过 100 字：正文允许纵向增长，图标按钮仍有语义，必要时工具栏换行。

小组件与菜单栏是独立紧凑表面，使用同一状态词和颜色语义，但不照搬主窗口卡片布局。
