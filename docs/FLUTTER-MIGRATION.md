### 蓝图工作区

- 「事项」可切换列表、四象限和蓝图；今日页与任务详情可跳转到对应蓝图。蓝图卡片直接打开画布，提供执行列表、任务信息、关系编排和参考图。事项目标、阶段、里程碑和蓝图或任务参考图可以在此查看和编辑。图片支持选择、拖入、粘贴、排序和放大预览，随现有 JSON 蓝图包携带。
- 工作流提供事项定位、阶段与里程碑跳转、画布缩放、适应画布、可撤销的自动排版及节点操作菜单。可选择两个节点预览增删连线，并通过串行、并行、拆分、插入和汇合的预览修改关系。就绪任务可批量启动，提交前统一检查依赖和旧状态。AI 草稿可以编辑任务及前置，跨阶段串联由用户选择。
- 已接入阻塞链、并行候选、估算关键路径、计划基线、改期推演、里程碑验收、可选成果图、本地复盘和蓝图模板复用。改期推演中的系统日历检查需要用户显式触发。


旧 SwiftUI 代码在 `legacy-macos/` 独立保留供对照与构建。旧 iOS 工程没有修改。Flutter 数据从空数据开始，不读取旧 SwiftData 数据。
