## 与业务方案一起评审

1. 默认进入周视图是否符合日常使用，还是更习惯先看月历？
2. 是否同意将「只有日期」与「明确时间段」分开，不为旧任务自动补一个小时？
3. 待安排清单放在时间轴旁是否方便，窄窗口收起后能否接受用按钮打开？
4. 日历容量是否应只计算实际占用，不重复累计父任务和子任务的估计？
5. 对有冲突的改期先展示影响、截止默认不变，是否符合预期？
