## 一致性规则

三种视图的右侧都包含「任务系列」标题、添加入口、「全部／待安排」筛选、系列展开箭头、主任务整体进度与截止、子任务完成状态及独立排期。共同保留展开、选择、筛选、滚动和列表宽度状态。

月视图不再把右侧换成单日议程；选择日期只突出相关子任务。其他日期和未安排的子任务继续按照当前列表筛选显示。窄窗口从右侧收起，不换到左边。

示例数据继续使用「新版发布准备」1/4 完成及「个人学习」0/2 完成。父任务是目标摘要，子任务才是具体时间安排；范围条不重复扣减时间容量。完整规则见[业务方案](../calendar-plan-redesign.md)。

## 生成方式与提示约束

内置 ImageGen，以 V2 三张稿为编辑来源，以修正后的 V3 周稿作为月／日右侧面板参考。生成目标1440×1024，保留暖白、深青、石墨、系统字体和应用导航。原图保留，交付副本位于本目录。

最终生成约束摘要：

- 周：任务树移到最右侧，中间紧邻应用导航显示完整七天；保留全部系列、子项、日期、范围和时间块。第一次输出遗漏周日，已重新生成补齐周一19日至周日25日，最终交付文件只采用修正版。
- 月：保留月格与系列跨度，原来的右侧日期议程替换为与周视图相同的完整系列树；保留全部七列和自然月日期。
- 日：将原左侧系列树移到右侧，中间保留14:00例会、15:00界面设计和16:00—18:00空档；选中子任务与系列进度延续，其他子项不伪造当日安排。

图片用于评审，不表示实际组件、拖拽或状态保留已实现。V2 作为历史稿保留，位置规则以本稿为准。
