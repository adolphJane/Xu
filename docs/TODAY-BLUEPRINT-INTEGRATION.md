# 今日任务与蓝图整合

版本：0.4.1（Build 5）

## 用户目标

“今日”不再是一张与长期计划割裂的清单，而是蓝图当天的执行入口。用户可以从今天正在做的事情，直接看到它推动了哪个目标。

## 已实现

- 今日任务按蓝图分组，同一项目蓝图下的事项集中展示。
- 每个蓝图展示今日完成数、剩余预计投入时间和蓝图总进度。
- 今日最重要的三项在所属蓝图内显示 1、2、3 顺序标记。
- 可从今日页直接打开对应蓝图详情。
- 未关联或原蓝图已删除的任务集中显示在“暂未归入蓝图”，避免任务丢失。
- 未归属任务可通过“归入蓝图”菜单快速建立关联。
- 蓝图详情首页新增“今日行动”，当天任务优先于阶段、里程碑和后续任务展示。
- 从蓝图详情新增任务时默认安排到今天并自动关联当前蓝图。

## 交互约定

- 完成、取消、延期、阻塞和恢复仍沿用任务卡片上的快捷操作。
- 将任务归入蓝图时会清空原阶段和里程碑关联，避免跨蓝图引用无效节点。
- 若任务原本没有项目名称，归入蓝图后自动采用蓝图名称；已有项目名称保持不变。
