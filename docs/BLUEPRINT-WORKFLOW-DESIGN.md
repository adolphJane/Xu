# 蓝图节点工作流设计方案

状态：核心交互已实现；本文记录当前实现口径与后续优化方向。

## 1. 目标与范围

蓝图从“阶段、里程碑、任务列表”升级为可视化任务依赖图。用户应能快速回答：当前能做什么、某项任务为什么还不能做、完成后会解锁什么。参考图用于画布、连线和属性面板的交互方向；节点内容遵循「序」的任务模型。

首版以**任务节点**为执行单元：一个节点对应一个现有 `TaskItem`。阶段在可收起的侧栏中导航；里程碑显示为阶段内的检查点和进度标记，不产生隐式依赖。只有用户明确连线，才建立执行顺序。节点图片完全可选，不影响节点是否可执行。

## 2. 信息架构与界面

蓝图卡片仍是入口。打开后进入可调整大小的工作流窗口，顶部保留蓝图名称、目标、完成率和状态，下面是「工作流 / 今日行动 / 时间安排」三个视图。工作流是默认视图；时间轴、周月计划继续作为时间安排的子视图。

```text
┌ 蓝图名称 / 目标 ─────────────── 进度  运行状态   搜索   撤销/重做   更多 ┐
│ 工作流  今日行动  时间安排                 ＋ 添加节点   自动排版   缩放 │
├ 可收起的阶段栏 ┬───────────────────────────────┬ 选中节点的详情 ┤
│ 阶段与里程碑   │       画布：节点、分支、汇合       │ 标题 / 说明     │
│ 阶段完成数     │       点选、拖动、连线、缩放       │ 图片 / 任务设置 │
│ 点击定位节点   │       空白处提示添加第一步         │ 依赖 / 后续影响 │
└───────────────┴───────────────────────────────┴─────────────────┘
```

- 左侧阶段栏默认收起，以节点旁的 `＋` 为主要创建入口；批量创建和加入已有任务可从顶部按钮打开。
- 中央画布支持平移、滚轮缩放、适应窗口、自动排版。连线统一从左向右，分支和汇合可一眼辨认；复杂蓝图可按阶段折叠。
- 右侧详情仅在选中节点时出现；不强迫用户创建节点前填写完整表单。未选中时显示当前可开始的节点和简短操作提示。
- 提供与画布同步的列表视图，供键盘操作、VoiceOver 和密集任务查看；主题色变化与“减少动态效果”设置沿用现有应用偏好。

### 节点卡片

卡片固定宽度，高度随内容变化。顶部是状态图标、标题和操作菜单；中间显示一行说明或首张图片的裁切缩略图；底部显示预计时长、计划日期、阶段以及依赖提示。有图片时显示缩略图和剩余图片数量；无图片时卡片保持紧凑，不出现空白图片区。点图片可放大查看，点卡片空白处选中节点。

状态以文字和图标共同表达，不只依靠颜色：

| 状态 | 卡片提示 | 主操作 |
| --- | --- | --- |
| 等待前置任务 | `等待 A、B 完成`，连线为灰色 | 查看前置任务；可编辑，不能开始或完成 |
| 可开始 | `现在可开始`，边框强调 | 开始 / 直接完成 |
| 进行中 | 显示已开始时间 | 完成 / 标记阻塞 |
| 手动阻塞 | 显示原因，区别于依赖等待 | 解除阻塞 / 编辑原因 |
| 已完成 | 勾选及完成时间 | 查看 / 撤销完成 |
| 已取消 | 显示后续受影响节点 | 恢复 / 调整连线 |

## 3. 低摩擦创建与编辑

1. **空蓝图**：中央显示“添加第一步”。输入标题按回车即创建，日期、象限、时长采用现有默认值；图片和详细设置都可以稍后再加。
2. **串行添加**：悬停或选中节点后，右侧显示 `＋`。点击后输入标题，自动创建下一节点并连线；回车可连续追加。
3. **并行添加**：`＋` 的菜单提供“并行一步”，新节点继承当前节点的前置关系，和当前节点可以同时执行。界面在创建前预览将形成的连线。
4. **插入与汇合**：点击连线上的 `＋` 可在两节点间插入任务；从一个节点的输出拖到另一节点的输入可连线。连接多个前置节点时，界面提示“全部完成后解锁”。
5. **批量创建**：粘贴多行文字，每行一个任务；可选整批串行或整批并行，提交前直接在输入框中修改。也可搜索未归入蓝图的已有任务并加入画布，避免重复创建。
6. **键盘与纠错**：沿用系统的 `Tab` 焦点导航；`⌘Z/⌘⇧Z` 撤销/重做画布操作。连线错误、跨蓝图连线或循环依赖都在提交前提示原因，并保持当前画布状态。

节点位置只影响排版；**连线才影响执行顺序**。移动卡片不会改变依赖。自动排版也不会改动连线。

## 4. 图片交互与保存

- 每个节点允许零张或多张图片；第一张是卡片封面。支持拖入、粘贴、文件选择，通过前移/后移按钮调整顺序，也可移除图片。图片不是创建节点的必填项。
- 画布显示压缩图片的缩略视图；点击后放大查看。导入失败时保留原节点内容并显示错误。
- 导入时将图片缩至适合画布查看的尺寸，并把压缩后的图片数据随节点存入本地数据库。节点不依赖用户原始文件路径，因此移动原图不会使蓝图失图。
- 图片随现有 JSON 快照、文件夹同步和蓝图导出一起传输；旧版无图 JSON 蓝图仍可导入。图片无法解码时显示“图片不可用”，任务和依赖照常可用。
- AI 蓝图与重新规划只接收文字任务信息；图片是否发送给 AI 应由单独的显式操作决定。

## 5. 执行与状态流转

工作流是有向无环图。一个任务的全部直接前置任务为“已完成”时，它才可开始或完成。没有前置任务的节点立即可开始。兄弟分支互不等待；汇合节点必须等所有进入它的分支完成。计划日期只决定何时显示在日历中，不自动解除依赖等待。

执行校验放在 `TaskStore` 的统一操作层，覆盖画布、今日页、四象限、菜单栏、快捷勾选和补记完成等入口。页面可以提示禁用原因，但不能成为唯一的校验层。蓝图暂停时保留当前状态，并阻止节点开始或完成；恢复后按依赖重新计算可执行节点。

关键例外按以下规则处理：

- **前置任务取消**：后续节点保持等待，明确标出“前置任务已取消”，提供替换前置任务或删除连线的操作，不静默放行。
- **删除带后继的节点**：先展示受影响节点，让用户选择重新连线或保留为无前置节点，再确认删除。
- **撤销前置任务完成**：若后继已开始或完成，先展示受影响范围；要求先回退后继，或通过明确的批量回退操作处理，不自动清除执行记录。
- **已完成节点新增前置连线**：如果新前置任务未完成，要求先回退该节点后才能保存连线。
- **旧数据异常**：保留现有任务状态和有效依赖；缺失或跨蓝图引用会阻止执行，可在节点详情中移除失效连线。新增连线会拒绝成环。

今日行动默认优先展示“现在可开始”的蓝图任务；已安排到今天但仍在等待的任务留在“等待前置任务”区，并说明原因。蓝图完成率继续依据任务完成数计算，同时显示“当前可执行 N 项”和“等待 N 项”。

## 6. 数据与落地顺序

现有 `TaskItem.dependencyIDs` 是任务间依赖的唯一事实来源。任务记录新增可选画布坐标与压缩图片数据；任务状态继续复用现有模型。新增字段保持可选，使旧版无图文件仍可导入。阶段、里程碑和无图任务均可原样迁入。

实施分四步：

1. 图校验与统一执行入口，先堵住“等待中仍可完成”的漏洞。
2. 画布、快速添加、连线、自动排版和列表替代视图。
3. 图片导入、缩略图、备份/同步及导入导出。
4. 今日与其他页面联动、AI 草稿适配、迁移测试和真实蓝图交互验收。

首轮验收至少覆盖：串行、并行、汇合；取消和回退前置任务；从任一页面尝试越级完成；有图/无图混排；图片原文件移动或删除；旧蓝图导入、复制、备份恢复；键盘与 VoiceOver 完成添加和执行。
