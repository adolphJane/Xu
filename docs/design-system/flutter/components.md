# 组件规范

组件名是 **Flutter 目标 API**，不是现有 `lib/src/` 已实现的类。先给确有跨页面重复的视觉结构建组件；`TextField`、`Checkbox`、`Switch`、`ProgressIndicator` 等优先沿用 Flutter 控件并由 `ThemeData` 统一样式。组件不直接访问 Repository 或持有业务记录。

## 基础组件

| 目标组件 | 契约 | 关键状态与可访问性 |
| --- | --- | --- |
| `XuPageHeader` | 一个 H1、可选说明、最多一个主动作；辅助动作进下方工具栏或菜单 | 窄窗口与大字体换行；标题不和按钮争宽 |
| `XuActionButton` | `primary / secondary / quiet / destructive`，`compact / regular / prominent` | loading 时禁用重复提交并读出“处理中”；disabled 有原因；图标+文字间 8pt |
| `XuIconAction` | 40×40 可操作区域、可见焦点和 tooltip | 必须有 `Semantics.label`，不能只靠图标表达动作 |
| `XuCardSurface` | 表面、16pt 圆角、1pt 边框、统一内边距 | hover 与 focus 有轻反馈；整卡可点时提供按钮语义与 Enter/Space 激活 |
| `XuStatusBadge` | 状态文字 + 可选图标；颜色由语义状态映射 | 不以颜色作为唯一信息；中文状态名称统一 |
| `XuEmptyState` | 线性图标、标题、解释、可选唯一主动作及快捷键提示 | 空数据、筛选无结果、权限拒绝分别写文案；今日空态按参考图居中 |
| `XuLoadingState` / `XuErrorState` | 说明正在做什么／失败在哪里，可重试时提供入口 | 不把错误当作空列表，不无限转圈 |
| `XuSectionHeader` | 分区名称、计数、说明及可选轻量操作 | 计数与业务数据同源；可组合读出 |

按钮尺寸与色彩遵循 [基础规范](foundations.md)。菜单栏和系统工具栏保持 macOS 原生外观；无需为了统一外观把所有 `NSMenuItem` 改成 Flutter 自绘菜单。

## 主导航和工具栏

- `XuSidebar` 参照[今日参考图](references/today-stone-reference.png)：顶部约 36pt 深青绿方形品牌标记、应用名与一句灰色说明；中部按「工作区」「记录」分组；「应用设置」锚在底部。行高至少 44pt，选中项使用 `selection` 底色及 `accent` 图标/文字，键盘上下移动和 Enter 激活，向 VoiceOver 报告选中态。
- `XuWorkbenchTopbar` 高约 64pt，左侧为低对比度路径与高对比度当前页，右侧为搜索/命令面板和主题名称。底部 1pt 分隔，不放页面筛选。页面自身的筛选、展示方式和批量操作在内容页头部；不把它们全部塞入同一横排。
- `Cmd+N` 添加事项、`Cmd+K` 命令面板、`Cmd+,` 设置；快捷键与菜单栏显示同一名称并调用同一 ViewModel 动作。按钮与快捷键都应在当前窗口恢复焦点。
- 状态栏显示正在执行的任务或临近纪念日；弹出菜单内今日任务有「开始／完成／取消」，再列添加、AI、命令面板、主窗口、小组件、设置与退出。禁用动作说明阻塞原因，菜单内容更新不得改变任务数据。

今日空态是 `XuEmptyState` 的业务配置：日出线性图标使用 `accent`，主句用 `sectionTitle`，辅助句用 `supporting`，实心按钮使用白字与突出尺寸，下方用两个小键帽展示 `⌘ N`。键帽只是提示，按钮和快捷键执行同一个添加动作。空态在可用内容区居中，不用大面积装饰卡承载。参考图的浅色选中背景与主按钮颜色来自[石墨主题 token](foundations.md)。

## 业务组件

### 任务系列卡 `XuTaskSeriesCard`

以根任务 ID 为稳定键。卡片顶部标记「独立事项」或「任务系列」；标题行放**唯一展开箭头**、完成控制、主标题、计划/截止摘要和更多菜单。直接子项进度、阻塞数量与状态以文字表示。默认收起；展开后子任务留在同一卡片内，按层级缩进并显示关系线。展开只改变视图状态，不改 `parentTaskID`、依赖、同步数据或匹配计数。

完成控制独立于展开和打开详情。被前置任务阻塞时保留可读原因，不默默忽略点击。主任务完成、子任务恢复与批量操作的业务规则只调用 ViewModel；组件不自行修改局部任务副本。卡片整行点击进入只读详情，编辑由明确的「编辑」操作进入。仅命中子任务的筛选结果仍保留主任务上下文，根任务不重复计入匹配数。

### 蓝图卡 `XuBlueprintCard`

包含名称、状态、两行内目标、完成百分比、进度条、阶段数、截止日期及归档标记。自定义蓝图色只用于窄色条与进度，文字和控制仍使用主题语义色。任务根节点派生的卡片标明「任务蓝图」、后代计数和“与列表/四象限共用任务”；点击进入同一任务 ID 构成的画布。卡片 hover、focus 和 Enter/Space 都可打开。

### 日历与计划

日期任务、执行时间块、截止提示、外部系统日程使用不同视觉类型。系统日程标出来源并保持只读；权限未决定、拒绝、同步失败、空日程分别显示。拖拽安排有键盘/菜单等效入口；计划冲突先预览旧/新时间与原因，再原子提交。任务系列概览与子任务执行块不得重复计入容量。

### 纪念日、日报与设置

纪念日卡显示名称或隐私替代名、下次日期、倒计时、历法类型与提醒状态；隐私模式在菜单栏与首页保持一致。日报区分草稿、生成中、已保存和失败；AI 建议必须先预览再保存。设置项显示当前值、作用范围和错误反馈；密钥字段不回显原文，不进入截图或日志。

## 表单与弹窗

目标是一个 Flutter `XuBusinessDialog` 容器：遮罩、20pt 表面、标题与关闭、可滚动内容、固定底部操作、焦点恢复、Escape 与外侧点击规则统一；嵌套只关闭最上层。任务、蓝图、分类、AI 预览及日报编辑复用此容器。**目前代码大量使用 `AlertDialog`，属于待迁移现状。**

新建/编辑任务按「标题 → 安排与截止 → 分类/蓝图 → 备注与子任务 → 高级设置」排序。必填校验在字段旁说明；保存中禁用重复提交，成功关闭后更新原页面；有未保存内容时 Escape、外侧点击和取消走同一放弃确认。危险删除和系统授权提示可使用原生 `AlertDialog`/系统面板。文件选择、钥匙串、通知授权、系统日历与安装流程继续由 macOS 原生桥接承担。

## 交互状态矩阵

| 场景 | 视觉与文案 | 操作 |
| --- | --- | --- |
| 任务完成 | 勾选、标题划线、「已完成」；短暂成功提示可另显 | 可恢复，保留完成时间的业务规则 |
| 阻塞 | 阻塞图标与原因文字；完成/开始禁用有说明 | 打开详情或解决依赖 |
| 空列表 | 区分“没有创建”与“筛选无结果” | 只给相关的创建或清除筛选动作 |
| 保存中 | 按钮显示进度和“保存中” | 禁止重复提交，保留表单 |
| 保存失败 | 错误原因可读、表单不丢失 | 重试或取消 |
| 同步冲突 | 双方版本、共同基线及受影响记录数 | 明确选择，取消不覆盖本地数据 |
| AI 草稿 | 生成中、预览、确认、失败分开 | 只有用户确认后写入工作区 |

每个新增组件需在 Gallery 或 widget test 中展示浅/深色、长中文、1.5 倍文字、禁用/加载/错误、键盘焦点与语义。验证方法见[验收矩阵](validation.md)。
