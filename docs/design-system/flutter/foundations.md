# 基础规范

以下是 Flutter macOS 的**目标 token**。默认浅色以[用户提供的「今日」参考界面](references/today-stone-reference.png)为基准，延续旧版「石墨」的青绿强调色和低饱和灰绿表面。截图采样色作为视觉锚点；深色是与之配对的设计提案，**不是从浅色截图推断出的现成界面**。实现时集中放入 `ColorScheme`、`TextTheme`、`ThemeExtension` 和尺寸常量，禁止在业务页面重复写 HEX。此表不表示当前代码已逐项接入。

以 `canvas` 为背景，浅色主文约 14.9:1、次文约 4.7:1、强调色约 8.2:1；浅色实心 `accent` 按钮使用白字（约 9.1:1）。深色实心按钮使用 `#1D2422` 字（约 8.2:1）。这些数值只覆盖表内组合；透明叠层、自定义蓝图色、背景图片和系统高对比度必须重新测量。

`ThemeMode.system` 跟随系统；手动浅/深覆盖系统外观。**默认浅色是石墨，不再以纸张暖棕色作为基准。**旧版「纸张、深海、森林、墨色」和自定义色属于扩展主题：先完成石墨浅/深语义映射，再逐个映射，不把旧版 HEX 直接塞入 `ColorScheme`。高对比度模式提高边框与焦点可辨性，文字/背景保持至少 7:1；任务完成仍保留勾选、划线和文字。状态色不能替代状态文字。

## 字体与内容

使用 macOS 系统字体及中文系统回退，不依赖 Material 默认的 Roboto 作为成品字体。Flutter `TextTheme` 统一定义角色；字号是 1.0 倍的基准，允许系统文字缩放，禁止用固定行高裁切中文。

| 角色 | 基准字号 / 字重 | 典型用途 |
| --- | --- | --- |
| `pageTitle` | 30 / Semibold | 页面唯一 H1 |
| `sectionTitle` | 20 / Semibold | 工作台分区 |
| `cardTitle` | 16 / Semibold | 任务、蓝图主标题 |
| `body` | 14 / Regular | 表单与正文 |
| `supporting` | 13 / Regular | 描述、日期、辅助操作 |
| `label` | 12 / Medium | 状态、数量、短标签 |

长中文标题默认可换两行；详情与表单正文可继续增长。只在导航、卡片摘要等明确有限区域使用省略，并提供可打开全文的路径。日期、计时、进度数字使用等宽数字；本地化时不拼接英文状态码。1.0、1.25、1.5 倍字号至少验证一次；文本放大时工具栏可以换行，底部主操作不可被遮挡。

## 间距、形状和层级

4pt 基础序列：`space1=4`、`space2=8`、`space3=12`、`space4=16`、`space5=20`、`space6=24`、`space7=28`、`space8=32`。页面水平边距 28（窄窗口 20）；区块间 24；列表卡片间 12；卡片内边距 16–20；图标与文字间 8。旧 SwiftUI 的 `AppSpacing.page=20` 与蓝图页 34pt 是历史实现，新 Flutter 页面统一从上述规则选择。

圆角：小标签/菜单项 8、输入与按钮 12、卡片 16、重点容器/业务弹窗 20。普通卡片用 1pt 边框，默认无明显阴影；只在弹窗、浮动面板和拖拽层使用阴影。深色模式用表面与边框区分层次，不堆叠半透明白色。

主窗口最小尺寸为 900×620（当前 `MainFlutterWindow`）。参考图的侧栏约 216pt、顶部工具区约 64pt、页面左右留白约 28pt；Flutter 常态侧栏采用 216pt，可在 210–236pt 内适配。主内容可用宽度低于 760pt 时，蓝图卡片、四象限和筛选工具栏改为一列/换行。页面内容随窗口宽度伸展，保留固定的页面边距。小组件按自身 300×260 的最小尺寸设计，不复用主窗口断点。

## 控件、焦点与动效

页面按钮可见高度：紧凑 28、常规 32、突出 38；图标按钮至少 40×40 的交互区域，任务行的状态/更多按钮至少 36×36。菜单栏保留系统菜单项尺寸。键盘焦点使用 2pt 明显轮廓，焦点位置与悬停位置不能只靠颜色区分。

轻量状态过渡 180–220ms ease-in-out；面板进入和布局变化不超过 350ms。按压可使用轻微透明度变化，非必要缩放不超过 0.985。系统 Reduce Motion 或应用减少动态效果开启时，取消位移、缩放与延时，保留状态变化和焦点转移。进度/计时每秒更新不应使整个页面重绘。

状态设计总是包含 `idle / hover / focus / pressed / disabled / loading / success / error` 中适用的项。加载动作禁止重复提交；失败说明下一步或重试方式。危险动作使用 `danger` 并在实际删除前确认。
