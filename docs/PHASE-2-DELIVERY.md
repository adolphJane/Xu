# 「序」第二阶段交付说明

- 版本：0.3.0
- 日期：2026-09-13
- 目标：完整计划能力、纪念日与主题皮肤

## 已交付

### 蓝图计划

- 蓝图详情新增概览、时间轴、周计划和月计划四种视图。
- 时间轴同时显示原计划虚线和当前计划实线。
- 支持任务前置依赖；循环依赖会被拒绝，前置任务未完成时不能开始执行。
- 展示计划进度、实际进度、阶段风险和阻塞数量。
- 支持未完成任务批量顺延；确认前预览变更，完成和取消任务不修改。
- 提供软件开发、学习、健身和旅行四类模板。
- 支持蓝图复制、归档、JSON 导入与导出。
- 日历页支持周/月计划容量查看，日报页支持周复盘归档。

### 纪念日

- 支持名称、日期、类型、备注、联系人和本地封面。
- 支持公历、农历，每年重复或仅一次。
- 提醒天数可在 0～365 天间自定义，支持首页、菜单栏和系统通知开关。
- 隐私模式只显示“重要日子”和倒计时。
- 可关联蓝图，并在设定提前期内展示准备任务预览；只有用户确认后才创建。

### 主题皮肤

- 内置跟随系统、纸张、深海、森林和墨色五套皮肤。
- 支持强调色、页面色、卡片色和四象限颜色配置。
- 支持字体缩放、紧凑度、圆角、阴影和背景纹理。
- 设置页实时预览、对比度提示和一键恢复默认。

## 数据与兼容性

- 第一阶段数据继续保存在 SwiftData，新增字段均提供兼容默认值。
- 新增纪念日和周复盘实体；DeepSeek 密钥仍只保存在 macOS 钥匙串。
- 蓝图导入失败不会写入半成品；导出使用带版本号的 JSON 文件。

## 验证范围

- Debug 与 Release 构建。
- 依赖循环和解锁规则。
- 纪念日重复日期计算。
- 任务依赖、纪念日、周复盘 SwiftData 往返。
- 蓝图传输文件编码和解码。
- 打包应用主窗口、纪念日页、蓝图模板入口和主题实时预览冒烟测试。
