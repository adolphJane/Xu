# 页面模式

本页规定信息结构与视觉层级，**不改变**任务规则或 Flutter JSON 格式。[用户提供的「今日」参考图](references/today-stone-reference.png)是默认视觉的第一参照；旧 SwiftUI 截图补充复杂状态与交互。最终验收在 Flutter 真机窗口完成。

## 主窗口框架

```text
┌─────────────────────────────────────────────────────┐
│ macOS 标题栏 / 窗口控制                              │
├──────────────┬──────────────────────────────────────┤
│ 序           │ 工作区 / 当前页 · 全局操作             │
│ 工作区       ├──────────────────────────────────────┤
│  今日        │ 页面标题                         主动作 │
│  事项        │ 说明 / 筛选 / 展示方式 / 批量操作        │
│  分类        │                                      │
│  …           │ 当前页面内容                          │
│ 记录         │                                      │
│  …           │                                      │
│ 设置         │                                      │
└──────────────┴──────────────────────────────────────┘
```

侧栏宽 216pt。用圆角底、实心图标和强调色标记选中项，用独立轮廓标记键盘焦点。顶部工具区约 64pt，左侧是位置，右侧是搜索、快速操作和可用的撤销、重做。页面正文和设置卡片随窗口宽度伸展，并保留页面边距。窄窗口下页头操作可换行，列表保持可滚动。主窗口最小 900×620。

侧栏顶部显示「序」方形标记与应用名，下方按工作区和记录分组，底部提供设置入口。蓝图和四象限是「事项」中的展示方式。今日页可通过「事项视图」跳转，任务菜单可直接打开对应蓝图。切页使用约 180ms 的淡入，展开系列时箭头旋转提示状态。系统开启减少动态效果时即时更新。

### 今日空态：参考图的基准构图

内容从上到下为：小号青绿色日期 → 30pt「今日」标题 → 一条细分隔线 → 中央空态。空态由日出线性图标、主句“今天还没有安排事项”、辅助句“从一件重要的事开始，安排好今天的节奏。”、唯一实心「添加事项」按钮和 `⌘ N` 快捷键提示构成。整组在标题下的可用内容区居中，图标与文字、主按钮之间留足空间；不能只显示一句“今天暂无事项”。

有任务时，空态整组替换为今日任务内容，主要添加入口移至页面头部；同一状态不重复出现两个同权重的添加按钮。日期和标题位置保持稳定。仅任务列表为空而日历/同步失败时，显示相应错误或权限状态，不用“没有安排事项”掩盖失败。

## 页面清单

| 页面 | 第一眼应看到 | 主动作 | 核心展示 | 必备状态 |
| --- | --- | --- | --- | --- |
| 今日 | 日期、单一「今日」标题、按蓝图执行的任务 | 添加事项 | 蓝图分组、未归属任务、完成进度、临近纪念日 | 参考图式空态、阻塞、加载、权限失败 |
| 收集箱 | 未安排且待处理的任务 | 添加事项 | 任务系列与分类/搜索 | 无数据、筛选无结果 |
| 事项 | 范围、数量、搜索、分类、列表／四象限／蓝图 | 添加事项 | 独立系列卡；默认收起，逐卡展开 | 待处理/收集箱/已处理/全部、阻塞、完成反馈 |
| 日历计划 | 日/周/月与选中日期、系统日历状态 | 安排事项 | 日期任务、时间块、外部日程、可用时段 | 未授权、空日程、冲突、同步失败 |
| 分类 | 类别名称、图标、使用数量 | 新建分类 | 类别卡与对应任务 | 默认/空类别、删除影响预览 |
| 纪念日 | 最近纪念日与倒计时 | 添加纪念日 | 公历/农历、隐私、提醒与准备任务 | 无日期、闰月、权限失败 |
| 已处理 | 已完成与已取消分区 | 恢复/查看 | 状态与完成时间 | 空历史、长列表 |
| 日报 | 当前日期与历史 | 创建/生成日报 | 生成预览、已保存内容、周复盘 | 生成中、长度校验、失败 |
| 设置 | 外观、数据、同步、通知、AI、更新 | 随设置项 | 当前值与生效说明 | 权限、密钥、同步冲突、更新失败 |

### 页面操作与布局

| 页面或入口 | 布局与交互路径 | 需要复查的情形 |
| --- | --- | --- |
| 1. 今日 | 页头保留日期与「事项视图」。有计划时查阅事项、展开系列、更新状态，最近的纪念日卡片可跳转。空态提供「添加事项」和 `⌘ N` | 当天有正在进行及已完成事项，搜索无结果 |
| 2. 收集箱 | 页头显示待安排数量。空态与有内容时均有「收集事项」。从事项菜单安排今天，事项随即进入今日 | 新事项没有计划日期，处理后剩余数量正确 |
| 3. 事项 | 范围、展示方式、搜索、分类与批量操作分层。展开、点击标题和更多菜单分别处理查看系列、编辑与状态变更 | 长标题与长分类名，搜索命中子任务，清空筛选，批量确认 |
| 4. 日历计划 | 日期切换和日／周／月控制在顶部。右侧任务系列可收起。底部图例和系统连接状态有独立图标及标签 | 窄窗口切换视图，安排时间块，冲突预览与撤销 |
| 5. 分类 | 页面入口集中在「新建分类」「新建任务」。类别面板用于浏览和切换分类，任务面板按选中类别和状态更新。新建或编辑时，可在图标库中按用途浏览或跨组搜索，保存分类后生效 | 未分类与长名称，重命名和换图标后的联动，删除前告知事项归属变化 |
| 6. 纪念日 | 空态给出添加路径。记录行显示倒计时、日历类型和下次日期，菜单提供编辑、准备任务预览与删除确认 | 公历与农历、日期计算异常、私密名称与封面、提醒权限 |
| 7. 已处理 | 按完成、取消、顺延筛选，搜索命中项可清除。记录沿用事项操作菜单，可恢复或追踪顺延 | 多种状态并存，搜索无结果，恢复后跨页面一致 |
| 8. 日报 | 「创建日报」打开日期与字数设置及草稿编辑。周复盘和历史日报有独立区块，已保存条目可阅读和复制 | 无历史、长日报、字数校验、生成失败仍可继续编辑 |
| 9. 设置 | 外观、提醒、AI 服务、应用更新、数据与同步各有一组图标、动作与状态。备份与同步控制可换行 | 切换外观，权限错误、同步冲突、更新下载反馈 |
| 10. 四象限 | 从「事项」或「今日 → 事项视图」进入。卡片使用不同图标、完整优先级标签和事项数量。窄窗口用单列 | 各象限空态和长标题，事项更新后数量准确 |
| 11. 蓝图库与工作台 | 入口与四象限相同。新建、模板、AI、导入、归档与变更记录集中在库上方。打开蓝图后可查看工作流、执行列表和详情 | 长节点名、依赖预览、并行开始、缩放与适应画布、参考图预览 |
| 快速操作 | 顶栏或 `⌘ K` 打开。输入关键词后用方向键选择结果，回车执行，Escape 关闭 | 空搜索结果、方向键滚动、焦点回到打开位置 |
| 桌面小组件与菜单栏 | 紧凑窗口显示今日状态及当前任务操作，菜单使用原生图标与快捷键。桌面小组件可打开主窗口 | 无任务、正在进行、长标题、不可执行操作状态 |

## 事项工作台

页面顺序：标题与一句说明 → 范围选择（带各范围计数）和列表／四象限／蓝图切换 → 搜索与分类 → “任务系列”结果标题和匹配数 → 系列卡片 → 结果说明/蓝图入口。默认范围「待处理」，默认列表，所有系列收起。范围切换清除展开状态；同范围内搜索、完成和视图切换保留用户手动展开状态。筛选只命中子任务时，主任务作为上下文显示但不加入匹配数。

系列卡顶部先给根任务状态与日期，再给直接子项进度和阻塞数；展开后的树线和缩进不能让长标题难读。主任务标题点击打开只读详情，完成圆圈立即提交并提供反馈，更多菜单保留编辑、添加子任务、安排、取消/恢复和删除。批量模式与普通点击有明确边界，危险操作先显示受影响任务与后代数量。

参考：[旧版事项 V3](../mockups/tasks-macos-v3.md)。其“默认收起、独立卡片、子任务归属、计数不变”是行为约束；色值和 SwiftUI 组件不是 Flutter 实现 API。

## 蓝图工作台

从「事项 → 蓝图」浏览项目蓝图和任务系列。这一视图保留事项的范围、搜索和分类筛选，项目卡汇总匹配的事项，未归入项目的任务系列可以单独查看。蓝图新建、AI 创建、导入、模板和变更记录集中在本视图工具区。

打开项目蓝图后默认展示画布。主工具区提供事项定位、阶段和里程碑跳转、适应画布、缩放、自动排版和子任务关系开关。排版作为一次可撤销的坐标变更提交。节点菜单可直接加串行、并行或中间任务，也可选择起点与后继来增删连线，保存前预览关系变化。

宽窗口的任务详情分为「任务信息」「关系编排」「参考图」，窄窗口通过「详情」切换。执行列表提供同一组状态和键盘可达的操作。「前置任务链」「后续受影响」「流程上可并行」都能定位回画布。

空库展示用途说明与唯一创建入口；导入错误保留当前库，撤销失败说明后来变更的冲突。完成进度来自任务 ID，阶段和里程碑不伪装为已完成任务。参考：[任务视图架构](../task-views-architecture.md) 与旧版 `legacy-macos/Sources/Quadrant/BlueprintViews.swift`。

## 日历、纪念日与日报

日历的日期任务、执行时间块、截止、外部系统事件必须在同一日期坐标中有不同样式。日/周/月切换后右侧任务系列清单位置与筛选保持一致；月视图选日期不把清单替换为另一套内容。时间冲突先预览，不让拖拽直接破坏安排。参考：[日历重规划](../calendar-plan-redesign.md)；此文含尚未落地的产品规则，Flutter 页面实现以迁移进度核对。

纪念日首先展示下一次发生日期与倒计时，再给类型、备注和准备任务。隐私模式在主窗口、通知、菜单栏统一隐藏真实名称。日报先让用户确认日期和字数，再展示草稿，最后保存或复制；历史是只读阅读，不与草稿混排。系统权限拒绝和 AI 生成失败都提供可继续使用本地内容的路径。

## 响应式与内容伸缩

- 900×620：主窗口最小尺寸。工具栏可分两行；弹窗可滚动且主操作不被裁掉；蓝图卡一列。
- 1200×800：标准工作台。侧栏和内容区同时可见；系列卡保持舒适行长；蓝图通常两列。
- 1600×1000 及更宽：页面内容随窗口伸展，保持两侧页面边距。
- 文字 1.5 倍、中文标题超过 30 字、蓝图目标超过 100 字：正文允许纵向增长，图标按钮仍有语义，必要时工具栏换行。

小组件与菜单栏是独立紧凑表面，使用同一状态词和颜色语义，但不照搬主窗口卡片布局。
