# Flutter 迁移进度

目标是用 Flutter 3.47.9 完整替换 macOS SwiftUI 应用。当前可运行版本尚未达到功能对等，不能作为正式版本发布。

已修复重复初始化 Flutter Binding 和脚手架存储导致的启动异常。真实运行与 `dist/序.app` 截图确认主窗口、侧边栏和“今日”首帧可见；后续每次发布需重复此画面验收，不能仅以构建成功或进程存在代替。
