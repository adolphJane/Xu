# 序内测版安装说明

## 安装

1. 双击打开 `序-unsigned-*.dmg`。
2. 将“序”拖入“应用程序”文件夹。
3. 首次启动时，在“应用程序”中按住 `Control` 点击“序”，选择“打开”，再确认“打开”。

这是未使用 Apple Developer ID 签名的内测版本，因此 macOS 会显示未知开发者提示；这是正常现象。请仅从可信来源获取该文件。

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon 或 Intel Mac

## 已知限制

- 尚未完成 Apple 公证，首次启动需手动确认。
- 无自动更新机制；更新时请下载新的 DMG 并替换“应用程序”中的旧版本。
