# 序内测版安装说明

## 安装

1. 双击打开下载的 `Xu-v*.dmg`。
2. 在打开的窗口中，将“序”拖到“Applications”快捷入口。
3. 如果首次启动出现安全提示，先尝试打开一次，再到“系统设置 → 隐私与安全性”点击“仍要打开”。仅在确认安装包来源可信时这样操作。

此内测版本使用临时签名，尚未通过 Apple 公证，因此 macOS 会显示开发者无法验证或无法检查恶意软件的提示。正式发布需要 Developer ID 签名和 Apple 公证。

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon 或 Intel Mac

## 已知限制

- 尚未完成 Apple 公证，首次启动需在系统设置中手动确认。
- 无自动更新机制；更新时请下载新的 DMG 并替换“应用程序”中的旧版本。
