# 「序」第三阶段交付说明

- 版本：0.4.0
- 日期：2026-09-13
- 目标：智能规划、跨设备同步与系统生态能力

## AI 智能规划

- 可用一句话、截止日期和每日容量生成完整蓝图草稿。
- 草稿包含阶段、里程碑和任务，创建前可编辑名称、日期、任务和时长。
- 蓝图详情可根据延期、阻塞、依赖及容量生成重新规划建议。
- 已完成和锁定计划的任务不会发送给 AI，也不会被 AI 修改。
- 项目名称和任务备注是否发送可在设置中单独关闭。
- 确认后的 AI 创建与重新规划保存前后快照，可在“AI 变更记录”中撤销。

## 同步与系统集成

- 通过用户选择的 iCloud Drive 或其他同步文件夹完成多 Mac 数据同步。
- 同步文件包含版本、设备、修订和 SHA-256 内容校验；本机和远端同时变化时要求用户选择安全合并、本机或远端版本。
- 启动时及运行期间每分钟自动检查同步，也支持手动同步。
- 系统日历默认关闭；用户单独授权后可读取未来日程，并在任务菜单中主动写入。
- 菜单栏标题显示当前任务计时或临近纪念日倒计时。
- ⌘⇧Space 打开全局命令面板。
- 菜单栏可打开“序小组件”紧凑窗口，快速查看、开始和完成当前任务。

说明：无 Apple Developer 账号的 ad-hoc 应用不能使用 CloudKit 容器或正式 WidgetKit 扩展，因此同步采用用户选择的 iCloud Drive 文件夹，小组件采用独立紧凑窗口；两者不依赖 App Store 签名。

## 高级主题

- 支持系统、圆体、衬线和等宽字体，以及彩色、单色和极简任务图标。
- 支持本地背景素材、高对比度和减少动态效果。
- 可保存多个个人主题，并导入、导出主题 JSON。
- 主题可按系统外观、时间或专注状态切换；专注状态可通过命令面板快速切换。
- 主题文件解码失败时保持当前主题不变。

## 备份与更新

- 支持完整 JSON、可阅读 Markdown 和任务 CSV 三种导出。
- JSON 恢复先校验数据结构，再要求用户二次确认。
- 支持可配置更新清单 URL、启动检查、版本比较、更新说明与下载入口。
- 更新清单样例位于 `Packaging/update-manifest.example.json`。
